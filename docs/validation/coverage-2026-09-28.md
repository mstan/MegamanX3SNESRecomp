To reproduce the accepted static program from a checkout with initialized
submodules and the verified ROM, run `bash tools/regen.sh --no-tests` and then
build normally. The generated program manifest SHA-256 must be
0417b3bf9468bb99e875534e818439812e9abf0ec2f7183503d5c0125fe4999e.
The normal regen script preserves the played candidate's analyzed program,
dispatch and generated instruction bodies. It now syncs declarations before

`bank_00_96F6` host alias declared by the generated header; it has no callers
and delegates to the interpreter. That alias and the generation identity are
the only C differences from the played candidate.
