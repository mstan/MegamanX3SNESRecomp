# Coverage and correctness survey, 2026-10-18

ROM CRC32: `FA0FE671`. SHA-256: `65b03268afac296330e8ff8d60dd0825879e13ed658b37713c034a3bd074f1d7`.

Framework: snesrecomp `48982940` (PRs #183 and #184), with recursively updated main/master dependencies. Generation policy lives in `recomp/generate.toml`; `tools/regen.sh` delegates to the framework. The recipe applies to developer regeneration and the launcher SDK. Generated C is never edited by hand or committed.

The USA checkpoint directory contains 53 records across 15 stage IDs. The survey exercised the stage loaders and selected checkpoint initializers, with selector readback. These are loader and movement observations, not proof of every boss defeat or ending. The full-stage reset and checkpoint-only initializer have different graphics prerequisites; a malformed teleport is not sufficient evidence of a renderer defect.

A trial harvested profile emitted the same 6006 AOT and 223 LLE variants as the existing inputs and reproduced all 30 comparison artifacts. It was redundant and is not adopted. Existing interpreter boundaries remain.

Adaptive widescreen requires a wide host window. The original 53-record survey used a 4:3 window and does not qualify expanded rendering. A separate original-stage entrance survey uses 1280x720 and verifies actual output widths.

The corrected TCP survey completed all fifteen original stage loaders plus movement/shooting, with selector readback and 342-pixel completed captures. Raw script PPU dumps alone are not evidence of the completed widened presentation.

Reference walkthrough: https://gamefaqs.gamespot.com/snes/588481-mega-man-x3/faqs/20930

Automated runs use a dummy output audio device while preserving audio emulation. Release defaults retain normal audio. Private ROMs, full memory captures, journals, and trial profiles remain outside the repository. A successful build or version string alone is not evidence of cross-build netplay compatibility.

Setup-pack generation also requires the native analyzer. The updated shared packager includes it and smoke-tests the staged SDK, so the bundled Python/C++ tools can generate without a Rust installation.
