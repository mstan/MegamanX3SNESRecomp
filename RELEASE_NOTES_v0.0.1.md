## Initial release

- First packaged Windows release of Mega Man X3 (USA) recompiled for native
  desktop execution.
- Includes the shared launcher, display and audio settings, key rebinding,
  crash diagnostics, and the built-in mod loader.
- The bundled **Mega Man X3 Widescreen** package is available from the
  launcher’s **Mods** page and is disabled by default.

## Notes

- Windows zip only. Extract the full archive, then run
  `MegaManX3SNESRecomp.exe`.
- A verified Mega Man X3 (USA) ROM is required and is not included.
- Widescreen is experimental.
